# Helixor Decision Runtime — Demos & Tutorials

In-process decision engine. Sub-millisecond. Zero tokens. No network calls on
the evaluation path. SHA-256 audit receipts. The current 0.2.x build is a
pure-Python reference implementation with a typed SDK for your language (see
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for exactly what it does and does
not protect).

## Quick Start (Clone & Run)

```bash
git clone https://github.com/HelixorAI/helixor-decision-demos
cd helixor-decision-demos
pip install /path/to/helixor_runtime-<version>-py3-none-any.whl   # licensed download, see below
python examples/01_quickstart.py
```

The examples call the Helixor runtime (`helixor-runtime`), which is **not**
included in this repository and is not published to a public package index.
It is proprietary software, distributed to users who hold a Helixor account
and have accepted the Helixor Software License Agreement. Download the runtime
wheel from your Helixor account and install it as above. Without it the
examples and `tests/test_use_cases.py` stop with `ModuleNotFoundError:
helixor_runtime`; there is no bundled substitute.

Once installed, the bundled Community engine ships with regulatory PII Guard
invariants (GLBA, PCI-DSS, HIPAA, GDPR, TCPA) ready to evaluate, with no API
key or configuration.

## What You Get on Install

When you install a Helixor decision pack, you receive **two artifacts**:

| Artifact | Purpose |
|----------|---------|
| **Runtime** (`helixor-runtime`, pure Python in 0.2.x) | The in-process decision engine. A native build is planned, not shipped. |
| **Typed SDK** (Python / Java / TS) | Generated by [`helixor-sdk-gen`](https://github.com/HelixorAI/helixor-sdk-gen) from the pack manifest. Every field, type, and constraint is correct by construction. |

See [`sdks/README.md`](sdks/README.md) for the generated SDK output.

## How the Runtime Works

```
Developer Code                    Helixor Runtime (in-process)   
┌──────────────┐                 ┌─────────────────────────────┐
│              │  evaluate()     │ Cryptographic Unsealing      │
│  Your App    │────────────────▶│ State Extraction (Codons)    │
│              │                 │ Invariant Evaluation         │
│              │  DecisionResult │ Remedy Synthesis             │
│              │◀────────────────│ Merkle Proof Generation      │
└──────────────┘                 └─────────────────────────────┘
                                  ▲
                                  │ load_pack()
                                  │
                                 .hxpack + .hxlic
```

The developer loads a pack, calls `evaluate()`, and gets structured results
with audit receipts. The runtime runs inside your process: the decrypted pack
is held in that process's memory and the pack key travels in the license, so
pack encryption is not an anti-inspection boundary against the licensee.
