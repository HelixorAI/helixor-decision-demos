# Generated SDKs

The typed clients in this directory are generated by Helixor's SDK generator
from the example pack's manifest (`embedded-pack-manifest.json`: its state
schema, rules, actions and codons), so field names, types and rules match the
pack. They are generated output: do not edit them by hand.

| Path | What it is |
|------|------------|
| `embedded-pack-manifest.json` | The pack manifest the SDKs were generated from. |
| `python/regulatorypiiguard/` | `models.py` (Pydantic state and result models), `client.py` (`RegulatoryPiiGuardClient` with `decide()` and `decide_batch()`), `runtime_bridge.py` (loads the native library, or the generated Python evaluator on request). |
| `java/` | Java records, a typed client and the compiled playbook's rules, with a `pom.xml`. |

## What runs today

The clients are written for a native runtime library (`libhelixor_runtime`),
which is **Planned** and not shipped. Without it:

- the Python client refuses to start unless you ask for the generated
  pure-Python evaluator with `allow_python_fallback=True`. That evaluator runs
  the pack's rules on a typed state; it has no audit ledger, so
  `get_audit_report()` raises;
- the Java client has no library to call.

`examples/08_generated_sdk_client.py` runs the Python client this way from a
clean checkout.

## Python usage

```python
import sys
sys.path.insert(0, "sdks/python")   # run from the repository root

from regulatorypiiguard import RegulatoryPiiGuardClient, RegulatoryPiiGuardState

client = RegulatoryPiiGuardClient(allow_python_fallback=True)
state = RegulatoryPiiGuardState(
    has_ssn=True, has_credit_card=False, has_health_record=False,
    has_email=True, has_phone=False, has_ip=False,
)
result = client.decide(state)
print(result.verdict)        # DecisionVerdict.REFUSE
print(result.is_approved)    # False
```

The client decides on a typed state (which facts are present), not on raw
text. To decide on text, use `helixor_runtime.HelixorEngine` as in
`examples/01_quickstart.py`.

## Java usage (Planned runtime)

The Java client uses the same state and result types. It calls
`ai.helixor.runtime.HelixorNativeRuntime`, which comes with the native runtime
library (Planned) and is not in this repository, so it does not build on its
own today:

```java
try (var client = new RegulatoryPiiGuardClient(bundlePath)) {   // java.nio.file.Path to a pack bundle
    var state = RegulatoryPiiGuardState.builder()
        .hasSsn(true).hasCreditCard(false).hasHealthRecord(false)
        .hasEmail(true).hasPhone(false).hasIp(false)
        .build();
    DecisionResult result = client.decide(state);
}
```
