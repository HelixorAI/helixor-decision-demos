# Tutorial Examples

Progressive walkthrough using PII Guard as the running example.
Each example builds on the previous, introducing one new capability.

## Tier 0: Clone & Run (no API key; needs the licensed runtime)

| # | File | What You Learn |
|---|------|---------------|
| 01 | `01_quickstart.py` | `HelixorEngine()` zero-arg constructor, evaluate text, read results |
| 02 | `02_batch_benchmark.py` | Throughput measurement — 47K ops/sec, P99 < 25µs |
| 03 | `03_prompt_interceptor.py` | LLM prompt privacy gateway — block or redact before dispatch |
| 04 | `04_streaming_interceptor.py` | Token boundary problem — in-flight redaction and fatal halting |
| 05 | `05_http_service.py` | HTTP/SSE microservice for polyglot consumers |
| 06 | `06_decision_protocols.py` | REST + SSE + WebSocket — all three transport protocols |

## Tier 1: Registered License

| # | File | What You Learn |
|---|------|---------------|
| 07 | `07_custom_rules.py` | Custom rule compilation gate — Community blocks, Developer unlocks |

## Generated SDK

| # | File | What You Learn |
|---|------|---------------|
| 08 | `08_generated_sdk_client.py` | Using the typed client generated by `helixor-sdk-gen` |

## Running

```bash
# Run any single example
python examples/01_quickstart.py

# Run the full tutorial
for f in examples/0*.py; do python "$f"; done
```
